# Bitácora del Termo

Blog de Elemental Asistencia Técnica con respuestas a las dudas más buscadas sobre termos eléctricos.

- Cada artículo es un archivo en `articles/<slug>.json`. Para publicar uno nuevo basta con agregar el archivo y hacer commit: Netlify reconstruye el sitio solo.
- `"status": "borrador"` dentro del JSON lo deja fuera del sitio.
- `node build.mjs` genera `dist/` con una página por artículo, `sitemap.xml` y `robots.txt`.
